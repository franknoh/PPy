# Reference

The pages you look things up in. There is no order to read them in; each
one is a table.

<div class="grid cards" markdown>

-   **[Diagnostics](diagnostics.md)**

    ---

    Every `E`/`W`/`R` code the checker, the converter, and the backends
    emit, and what it means. `ppy explain E1301` prints the same text.

-   **[Configuration](config.md)**

    ---

    Every key under `[tool.ppy]` in `pyproject.toml`, with its default. A
    CLI flag overrides it for one invocation.

-   **[Performance](performance.md)**

    ---

    collatz kernel and six judge problems.

-   **[Compatibility](compatibility.md)**

    ---

    What is stable and what moves, what the cache and the artifact ABI
    promise, and the platform and C-library floor.
